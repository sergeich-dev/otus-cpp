# Bulk
Утилита для многопоточной асинхронной обработки команд.

## Пример использования после установки пакета

async 3

где 3 - размер блока команд для обработки

## Результат

На консоль выводятся блоки команд в виде: 

bulk: testCmd6, testCmd7, testCmd10

Также блоки сохраняются в файлы в том же виде, пример имени:

bulk_1_1769444358_123506306037440.log

где 
_1_ - уникальный id первой команды из блока, 
_1769444358_ - время получения первой команды из блока, 
_123506306037440. - id потока, который обработал блок
